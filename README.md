# Thai Quotation Generator (ระบบสร้างใบเสนอราคา)

A modern, responsive, 100% client-side web application for generating professional Thai quotations with real-time preview and pixel-perfect multi-format export (**Excel .xlsx**, **PDF**, **PNG**, and **Print**).

Designed to match standard commercial Thai quotation layouts with 100% fidelity to reference Excel templates (`ใบเสนอราคา`).

---

## ✨ Key Features

- **100% Client-Side & Private**: Runs entirely in the browser with zero backend requirements. Your customer details, pricing, and bank account information never leave your device.
- **Pixel-Perfect Excel Export (`.xlsx`)**:
  - Uses `ExcelJS` to build workbooks matching reference commercial templates 100%.
  - Preserves exact column widths, row heights, Thai fonts (`Angsana New`), merged headers, borders, and live Excel `SUM(F12:F28)` formulas.
  - File names are automatically formatted and sanitized: `ใบเสนอราคา_[ชื่อลูกค้า]_[เลขที่เอกสาร].xlsx`.
- **High-Resolution PNG (2x Retina)**:
  - Rendered via `html2canvas` at 2x scale for crystal-clear readability when sharing via LINE, WhatsApp, or email.
- **1-Page A4 PDF & Print Ready**:
  - One-click PDF generation via `jsPDF` configured for A4 portrait fit (`210mm x 297mm`).
  - Custom `@media print` CSS ensures clean printouts with controls and modals hidden.
- **Automated Thai Baht Text Conversion (`bahtText`)**:
  - Automatically translates monetary sums into formal Thai text (e.g. `57,552.90` ➔ `(ห้าหมื่นเจ็ดพันห้าร้อยห้าสิบสองบาทเก้าสิบสตางค์)`).
  - Accurately handles integer baht, floating satang, and boundary values.
- **Smart Quotation Numbering (`QT-YYYYMM-XXXX`)**:
  - Monotonically increasing auto-increment sequence with automatic monthly reset (e.g., `QT-202611-0001`).
  - Collision-resistant: deleting records from history does not regress the counter.
- **Dynamic Row Management**:
  - Add main priced items (`type: 'item'`) with automatic number re-indexing.
  - Add nested specification bullets (`type: 'bullet'`).
  - One-click Payment Terms preset (e.g., "เบิกมัดจำ 70% และ 30% เมื่องานเสร็จสิ้น").
- **Auto-Save Drafts & Local History**:
  - Changes are auto-saved to browser `localStorage` as you type.
  - Searchable quotation history with duplicate, edit, and delete functionality.
- **Customizable Seller Profile**:
  - Easily configure your business name, address, phone numbers, and bank account via the settings modal.

## 🚀 Quick Start & Usage

### 1. Running the Application
No build steps or server setup required! You can use any modern browser:

**Option A: Direct Open**
- Simply double-click `index.html` or open it directly in Google Chrome, Apple Safari, Microsoft Edge, or Mozilla Firefox.

**Option B: Local Static Server**
```bash
# Using Node.js
npx serve .

# Or using Python 3
python3 -m http.server 8000
```
Open your browser and navigate to `http://localhost:8000` (or the port indicated).

## 🛠️ How to Use

1. **Configure Seller Profile**:
   - Click **"ตั้งค่าข้อมูลผู้ขาย" (Seller Settings)** in the navigation bar.
   - Enter your company/seller name, address, contact telephone numbers, and bank account details.
   - Click **"บันทึกข้อมูล" (Save Profile)**. This profile will automatically populate all new quotations and persist in your browser.

2. **Create a Quotation**:
   - **Customer Info**: Fill in customer name, address, job title, and document date.
   - **Quotation Number**: Auto-generated by default (e.g., `QT-202611-0001`), or customize as needed.
   - **Line Items**:
     - Click **"+ เพิ่มรายการหลัก"** to add a numbered product or service row with quantity and unit price.
     - Click **"+ เพิ่มข้อย่อย (Bullet)"** to add descriptive bullet notes under an item.
     - Click **"+ เงื่อนไขการชำระเงิน"** to insert standard commercial payment terms.

3. **Export and Share**:
   - **Export Excel (.xlsx)**: Downloads an Excel workbook matching the reference template structure with active `SUM` formulas.
   - **Export PDF (.pdf)**: Generates a single-page A4 PDF document ready for printing or attaching to emails.
   - **Export PNG (.png)**: Downloads a high-resolution 2x retina image ideal for messaging apps.
   - **Print**: Opens the browser print dialog with page margins and headers optimized for paper output.

4. **Quotation History**:
   - Click **"บันทึกเอกสาร" (Save Document)** to store the quote in history.
   - Click **"ประวัติใบเสนอราคา" (History)** to browse past quotations, search by customer or doc number, restore a quote, or duplicate a past quotation into a new number.

## 🧪 Automated Testing

The project includes a comprehensive automated test suite verifying everything from Baht text conversion to Excel workbook formulas and DOM bindings.

### Running Tests
Make sure Node.js (v18+) is installed:

```bash
# Install dependencies (ExcelJS for test verification)
npm install

# Run the complete test suite
npm test
```

### Test Suites Included:
1. `test/bahtText.test.js`: Validates Thai Baht text conversion across zero, integers, decimals, and edge cases.
2. `test/storage.test.js`: Validates LocalStorage sequence numbering, collision prevention, seller profile fallback, and history CRUD.
3. `test/excelMatch.test.js`: Compares generated Excel workbooks against the reference template structure (`column widths`, `row heights`, `cell merges`, `headers`, and `SUM(F12:F28)` formula).
4. `test/pdfExport.test.js`: Tests `exportToPNG` (2x retina scale) and `exportToPDF` (A4 210x297mm fit) with DOM and library mocks.
5. `test/app.test.js`: Tests Alpine.js controller state, re-indexing, calculations, and autosave.
6. `test/indexHtml.test.js`: Tests HTML structure, CDN versions, Tailwind styles, and print stylesheets.
7. `test/e2e.test.js`: Full end-to-end integration workflow validating the entire lifecycle from initialization to export and Git cleanliness.
